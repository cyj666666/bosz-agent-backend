| 顺序 | 文件 | 说明 |

### 🔴 这里有个**必须手工补**的东西：`admin` 用户

实测：**仓库里没有任何"创建 admin 用户"的 SQL**。
`AuthInitializer` 的 `initDefaultAdmin()`（创建 `admin` / `admin123`）**写在 `app.init-sql-on-startup=true` 分支里**，
而该开关**默认 `false`** → **光跑上面 4 个脚本，新库里没有能登录的账号。**

**两种做法，选一种：**

**做法 A（推荐，可控）：手工插 admin**
```sql
-- ① 角色（admin 的菜单权限走代码里的 '*' 分支，此处空数组即可）
INSERT INTO sys_role (role_code, role_name, description, menu_permissions)
VALUES ('admin', '系统管理员', '拥有所有权限', '[]');

-- ② 用户：password 必须存 BCrypt 密文，不能明文
--    取值方式：在你现有库执行  select password from sys_user where username='admin';
--    把结果原样粘到下面（这样密码与你现有环境一致）
INSERT INTO sys_user (username, password, real_name, status)
VALUES ('admin', '<从现有库复制 password 字段>', '系统管理员', 1);

-- ③ 绑定
INSERT INTO sys_user_role (user_id, role_id)
SELECT u.id, r.id FROM sys_user u, sys_role r
 WHERE u.username = 'admin' AND r.role_code = 'admin';
```
> 💡 若没有可复制的密文，可临时把 `app.init-sql-on-startup` 置 `true` 启动一次让它自动建
> （`admin` / `admin123`），**建完立刻改回 false** —— 注意它同时会跑 `init_db_gaussdb.sql` 和示例数据。

**做法 B：直接用 `app.init-sql-on-startup=true` 启动一次**
会依次执行：认证表 DDL → 业务表 DDL → 示例数据 → 建默认管理员（`admin` / `admin123`）。
⚠️ **会把示例数据一起灌进去**，现场要慎重。

## 步骤 ② 建表（DDL）

| 项 | 内容 |
|---|---|
| **文件** | `三菜单DDL/三个菜单_建表DDL.sql` |
| 内容 | **44 张表**、730+ 条语句（44 CREATE + 列注释 + 41 表注释 + 10 索引 + 3 ALTER） |
| 前置 | 已 `SET search_path`（脚本内表名是**裸名，不带 schema**，换任意 schema 都能用） |
| 特性 | **无外键**（执行顺序无关）、**无 CREATE SEQUENCE**（id 用 `AUTO_INCREMENT`）、**无 `IF NOT EXISTS`**、**无 `ALTER TABLE`**（3 条加宽语句已内联进列定义，见下） |
| ✅ 已内联 | `agent_rule.rule_text` / `parsed_expression` = `TEXT`、`index_params.columncomment` = `VARCHAR(1000)` 已直接写进列定义（原公司脚本用 MySQL 风格 `MODIFY COLUMN` 事后加宽，已改为内联，避免纯 PG 模式不兼容） |
| 静态体检 | ✅ 引号闭合 / 括号配平 / 无重名 / 无 schema 前缀（`D:\dbtool\ddl_lint.py`，不连库） |
| ⚠️ | 表已存在会**直接报错**（预期行为）。→ **本地库别跑整份**（44 张都在，会报 44 次）；空库才能一次跑通 |
| ⚠️ 本地一处偏差 | 本地 `as_agent` 是早前用 `agent_模块建表_as_agent.sql` 建的，**那 3 列仍是窄的**（`agent_rule.rule_text`/`parsed_expression` = `VARCHAR(1000)`、`index_params.columncomment` = `VARCHAR(100)`）。<br>→ 本地自测长规则正文可能踩截断；要加宽需单独执行（**属写操作**） |

```sql
-- 跑完自检（期望 44）
SELECT count(*) FROM information_schema.tables
 WHERE table_schema = current_schema()
   AND table_name IN ( /* 44 张表名，或用报告文档里的清单核对 */ );
```
