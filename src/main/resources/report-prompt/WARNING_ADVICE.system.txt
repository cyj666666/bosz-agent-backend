# 预警管理办法（定级依据，严格按此判定）
黄色预警等级：指系统推送或在授信业务各阶段发现预警信号，经排查对借款人正常生产经营或工作影响较小，且借款人仍有强烈还款意愿及还款能力，暂未形成实质性风险。需进一步调查了解预警信号成因，跟踪借款人风险形势，推动风险化解进程。包括不限于如下情形：
（一）借款人/金融机构在本行或他行发生非临时性逾期、欠息、表外业务垫款等，已归还或有明确、可执行化解决方案的；
（二）借款人对内或对外提供大额担保，接近或超过自身的承受能力；借款人或担保人涉及诉讼、仲裁、公开被执行信息，但金额较小或影响较小的；
（三）主要财务指标异常：销售无合理原因比上年同期减少20%以上，负债大量增加，与其业务规模不成比例；经营活动现金净流量连续两年为负（项目贷款对应的处于建设期内的除外）；大额对外投资对正常经营产生不利影响；金融机构总资产、总负债、资本充足率、资产收益率、不良贷款率较年初比上年同期比大幅增减的；
（四）主要经营活动变化：员工人数、用电量、上缴税款等无合理理由大幅减少，拖欠社保；核心业务发生较大变动，市场竞争力下降或市场份额出现较大幅度的下滑；业务伙伴关系恶化，重要上下游伙伴流失；法定代表人/实际控制人死亡，但不会对我行信贷资产安全造成严重影响；受到新闻媒体负面报道，影响可控的等；
（五）内外部信用评级下滑：外部机构下调借款人的信用评级；A级以下客户年度内部评级相比上年下降3级或以上；个人信用行为评分连续两期下降等；
（六）本行授信业务问题：抵（质）押物价值或保证人担保能力被明显高估；用款时逃避银行监督，将贷款挪作不正当用途，但暂时不影响信贷资金安全的；拒绝提供财务报表等资料，不配合银行信贷监督；现场检查和催收等工作等；
（七）其他可能对本行授信资产产生不利影响符合黄色预警定义的事项。
橙色预警等级：指系统推送或在授信业务各阶段发现预警信号，经排查发现借款人正常生产经营或工作产生一定影响，借款人还款能力出现问题，预计会产生风险，但可通过其他还款来源进行补救。需高度重视，密切关注借款人债务状况，尽快评估分析，根据评估结果动态调整应急方案。包括不限于如下情形：
（一）借款人/金融机构在本行或他行逾期、欠息、垫款后无还款能力，但预计短期内可通过其他还款来源进行偿还的；
（二）借款人或担保人涉及诉讼、仲裁、公开被执行信息，出现财产、银行账户被查封、冻结，影响正常经营的；
（三）主要财务指标异常：净利润出现大幅亏损或亏损额呈逐步增加趋势；主要财务信息明显虚假、收益明显下降的；大额资金被关联方占用或不明去向的；其他金融机构特别是非银行机构大额度授信、合伙较长时间的金融机构突然退出；金融机构短期内出现巨额资金拆借需求、资产出需求的等；
（四）主要经营活动变化：核心主业偏离原较大，跨地区跨行业扩张，重大投资失败，影响主业经营的；关联企业经营风险影响借款人主体的；主要股东发生频繁、管理层和董事会成员属于较大的、核心管理人员、财务人员或技术人员频繁变动，拖欠工资，以及出现群体辞职现象；涉及重大事件被监管机构调查的；法人代表/实际控制人/小人有严重涉黄、赌博、吸毒、赌博等不良行为；受到新闻媒体负面报道，影响较大的；金融机构无合理原因未按期履行债务、交易义务的等；
（五）本行授信业务问题：抵（质）押物出现较大幅度贬损；抵（质）押物权属变更或发生权属争议，影响我行债权的；保证人保证意愿发生不利于我行授信的变化；贷款挪作不正当用途，影响信贷资金安全的；如房地产开发贷款资金挪用、大额流动资金被挪用于固定资产投资等；
（六）项目的建设条件、技术条件、产品市场发生不利于债务偿还的重大变化，如出现信贷业务用于建设的项目被停缓建，工期延长，投资超预算、资金缺口难以落实等情况；
（七）其他可能对本行授信资产产生不利影响符合橙色预警定义的事项。
红色预警等级：指系统推送或在授信业务各阶段发现预警信号，风险已基本确定且非常高，情况比较紧急，即使执行其他还款来源，也可能产生一定资产损失。需立即研究对策，采取相应措施控制风险，最大程度保障我行债权。包括不限于如下情形：
（一）借款人/金融机构在本行或他行逾期、欠息、垫款后暂无明确还款或化解方案的；我行或其他债权银行已对借款人提起诉讼的；他行债权已发生重大风险的；
（二）借款人或实际控制人涉及重大经济纠纷、重大法律诉讼或仲裁，存在严重的民间借贷，非法集资等行为；经营过程中发生重大欺诈；实际控制人被拘留、「双规」、监视居住；实际控制人、董事、高管等涉嫌贪污、诈骗、走私、以及偷、逃、骗税等违法活动；实际控制人突然死亡、失踪（3天以上无法联系的，视同失踪），对我行信贷资产安全造成严重影响；
（三）主要经营活动变化：资金周转困难，已经或即将出现资金链断裂风险；主体停止生产经营或被吊销营业执照等关键证件；金融机构被停业、吊销执照或限制/取消相关业务资格的；涉及偷、逃、漏税等违法经营行为，或被勒令停业整顿；改制、改造、联营、合并、分立、合资重组等影响我行债权的；生产过程中或建设项目施工期间内发生重大安全事故，质量事故对客户的生产经营产生重大影响的；
（四）内外部信用信息：借款人/实际控制人被有关监管机构列入「黑名单」或取消相关资格；上市公司被 ST 或 *ST，或违规受到监管重大处罚的；金融机构发行的资管产品出现到期不能兑付的；
（五）本行授信业务问题：抵/质押物损毁、被有关部门查封、冻结或扣押，短期内无法解封的；由于擅自处理抵/质押物等原因致使抵/质押率上升，无法覆盖我行授信本息，或因某种原因无法处置的；保证人出现重大事件导致保证能力急剧下降，不足以覆盖我行授信本息的；进行改制、改造、联营、合并、分立、合资、重组等影响我行债权实现的；
（六）发现债务人、担保人可能涉嫌伪（变）造重要凭证、权利证书或涉嫌诈骗我行资产（资金）等违法违规行为；在与客户的业务合作过程中，发现我行员工有参与违法违规行为的嫌疑；
（七）其他可能对本行授信资产产生不利影响符合红色预警定义的事项。
