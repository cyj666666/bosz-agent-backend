# 行内同步台账

> **用途**：维护「外网 `bosz-agent-backend`」↔「行内 `szbank/aimp-plma`」两条线，支持**增量合入**。
> **机制**：**双锚点 + 指纹**
> - 外网侧是 git 仓库 ⇒ 用 **commit SHA** 做锚点，下次增量直接 `git diff <锚点>..HEAD`
> - 行内侧是与外网**无共同 git 历史**的单提交快照 ⇒ 用**内容指纹**（剥离 UTF-8 BOM / CRLF 后的 SHA1）
>
> ⚠️ 行内仓库不能 `git diff` / `merge` / `cherry-pick`，**只能指纹比对 + 逐文件搬运**。
> ⚠️ 判定口径：**行内现态指纹 ≠ 台账指纹** ⇒ 行内被行内团队改过（**漂移**）⇒ 该单元必须**三方比对**，不可直接覆盖。

### 指纹计算脚本（可复现）

```powershell
function HashOf([string]$p){
  $b=[System.IO.File]::ReadAllBytes($p); $s=0
  if($b.Length -ge 3 -and $b[0] -eq 0xEF -and $b[1] -eq 0xBB -and $b[2] -eq 0xBF){ $s=3 }
  $ms=New-Object System.IO.MemoryStream
  for($i=$s;$i -lt $b.Length;$i++){
    if($b[$i] -eq 13){ if(($i+1) -lt $b.Length -and $b[$i+1] -eq 10){ continue } else { $ms.WriteByte(10); continue } }
    $ms.WriteByte($b[$i])
  }
  $sha=[System.Security.Cryptography.SHA1]::Create()
  return ([System.BitConverter]::ToString($sha.ComputeHash($ms.ToArray()))).Replace('-','')
}
function DirHash([string]$p){
  $lines = Get-ChildItem $p -Recurse -File | ForEach-Object { $_.FullName.Substring($p.Length+1) + '|' + (HashOf $_.FullName) } | Sort-Object
  $bytes=[System.Text.Encoding]::UTF8.GetBytes(($lines -join "`n"))
  $sha=[System.Security.Cryptography.SHA1]::Create()
  return ([System.BitConverter]::ToString($sha.ComputeHash($bytes))).Replace('-','')
}
```

> **目录指纹规则**：把 `相对路径|文件SHA1` 按字典序排序后用 `\n` 连接，再算一次 SHA1。
> 因此它对**文件顺序、编码、换行符**不敏感，只对**内容集合**敏感 —— 适合做漂移检测。
