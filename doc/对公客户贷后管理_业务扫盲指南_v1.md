# 对公客户贷后管理 · 业务扫盲指南

> **给谁看**：完全没接触过银行信贷业务的人；或者懂系统、但说不清业务的人。
> **读完能干什么**：看懂一份对公贷后检查报告为什么长这样；知道客户经理在担心什么；能跟业务部门用业务语言对话。
> **日期**：2026-10-15

---

## 第一部分 · 先把大背景搞懂

### 1.1 银行给企业放一笔贷款，要经过哪几步

一笔对公贷款从无到有，业务上分三段：

| 阶段 | 通俗说法 | 银行在干什么 |
|---|---|---|
| **贷前** | "要不要借、能借多少" | 调查客户、评信用等级、核定**授信额度**、上审批会 |
| **贷中** | "签字、放钱" | 签合同、落实担保（抵押登记/保证）、**放款**、每一笔出一张借据 |
| **贷后** | "借出去以后盯住" | **持续跟踪客户和这笔钱**，定期形成书面检查记录 |

**关键认知**：贷前做得再细，钱出去以后客户会变——经营会变差、股东会换人、抵押物会被查封、老板会去别处借钱。所以**贷后管理不是形式主义，是银行控制损失的最后一关**。

> 一句话：**贷前决定"借不借"，贷后决定"什么时候发现出事了、还来不来得及跑"。**

### 1.2 为什么贷后管理是监管硬要求

对公客户贷款发放后，监管明确要求银行：

1. **必须持续跟踪**资金实际用途（有没有被挪用）；
2. **必须定期检查**客户经营状况、财务状况、担保情况；
3. **必须形成书面记录**（检查报告），可追溯、可问责；
4. **发现风险必须预警、必须采取措施**（压降、追加担保、提前收贷）。

检查频率通常按客户风险等级和贷款类型确定（常见：每季度一次、每半年一次、每年一次）。风险高、金额大的客户，检查更密。

> **考核提示**：能说出"贷后检查是监管强制动作，不是可选动作"，就抓住了这个业务的根。

### 1.3 谁在做、做什么

| 角色 | 干什么 |
|---|---|
| **客户经理** | 第一责任人。现场走访、收集资料、写检查意见、落实批复要求 |
| **检查/审查岗** | 复核客户经理的检查质量，看有没有漏项、有没有"走过场" |
| **风险管理部门** | 接收预警、判断风险等级、决定是否采取措施 |
| **审批人/支行行长** | 对重大风险处置拍板 |

**日常动作**：
- 去企业**现场走访**（要有打卡记录，证明真去了）
- 收集最新**财报、纳税、银行流水、征信报告**
- 对照**授信批复时提的管理要求**，逐条看落实情况
- 判断有没有**新风险**，写进报告
- 有风险的，**发起预警**

### 1.4 一份对公贷后检查报告长什么样

这是本项目的核心产物。一份完整的日常定期检查报告分 **12 个章节**：

| 章节 | 名称 | 在回答什么问题 |
|---|---|---|
| 一 | **总结概述** | 这次检查发现了什么风险？重点是什么？ |
| 二 | **客户基本情况** | 这家公司还是不是原来那家公司？（工商、股东、实控人） |
| 三 | **业务基本情况** | 我们跟它的业务往来是什么？（授信、用信、借据、还款） |
| 四 | **本次检查开展情况** | 这次检查怎么做的？（打卡、批复要求落实、专项检查） |
| 五 | **财务指标变化和潜在风险** | 钱赚得怎么样？欠得怎么样？ |
| 六 | **征信情况和潜在风险** | 它在外面的负债和查询记录有没有异常？ |
| 七 | **资金疑似回流或用途异常** | 我们借出去的钱，有没有绕回它自己或关联方？ |
| 八 | **潜在合规风险关注点** | 有没有踩监管红线的地方？ |
| 九 | **结算情况和潜在风险** | 业务是不是真的在做？（账户、交易对手、代发工资） |
| 十 | **地方征信和潜在风险** | 地方征信渠道还有没有别的信号？ |
| 十一 | **预警信息和潜在风险** | 系统/行内已有的预警是什么？行业环境怎么变？ |
| 十二 | **担保情况和潜在风险** | 抵押物还值钱吗？担保人自己有没有问题？ |

> **这份结构本身就是"贷后检查清单"**。客户经理原来靠脑子记、靠模板抄，
> 现在系统按这 12 章自动把数据摆好、把风险挑出来。

## 第二部分 · 12 个维度逐一讲透

### 一、总结概述

**作用**：30 秒抓住重点。

三个层次：
1. **风险要点**——把全篇命中的风险挑出来，先说结论（"本次检查共发现 X 项风险"，然后逐条列），最后给一段总体判断。
2. **检查重点**——本次检查特别关注的：
   - **上一次贷后检查意见**：上次提的问题，这次改了没有？（**闭环检查**）
   - **最近一次已审批预警意见**：行内已经认定的预警，现在什么状态？
3. 剩下的部分展开详述。

> 🔴 **业务逻辑**：贷后检查最怕"上次说了、这次没人管"。所以**每一次检查都要回看上一条意见的落实情况**，这是监管最爱查的点。

### 二、客户基本情况（工商维度）

**查什么**：
- 企业名称、统一社会信用代码、成立时间、注册资本、实缴资本
- 法定代表人
- 经营范围、行业、企业规模、组织性质（国企/民营/外资）
- **股东结构**（谁持股多少）、**实际控制人**、**实际受益人**
- 是否上市、是否国有企业、是否"假冒国企"

**为什么查**：
1. **主体变了没有**——公司改名、法人换了、股东换了，意味着控制权可能变了。
2. **注册资本实缴了没有**——注册资本 1 个亿但实缴 100 万，说明股东没真掏钱，抗风险能力虚。
3. **是不是国有企业**——国企背景通常意味着更强的隐性支持；反过来，**冒用国企名义**（假冒国企）是重大风险信号，监管重点打击。
4. **股权是否稳定**——授信期间股东大换血，原来的还款逻辑可能就不成立了。

> 🔴 **一个关键业务概念：工商口径 vs 银行系统口径**
>
> 同一件事，银行会看到**两套数据**：
> - **工商口径**：市场监管部门登记的信息。企业自己申报，变更后按申报时间更新。
> - **系统口径**：行内信贷系统里客户经理手工录入/维护的信息。
>
> 两者**经常不一致**——可能工商早就变更为新股东了，但客户经理没及时更新系统；也可能客户经理录错了。
>
> 所以贷后检查要**把两套摆在一起比**：
> "工商登记的实际受益人和系统里记录的实际控制人对不上"——这本身就是一条风险。
> **不是简单地信谁，而是差异必须解释清楚。**

### 三、业务基本情况

**查什么**：
- 我们给它的**授信额度**是多少、什么品种、什么期限
- 实际**用了多少**（提款）
- 每一笔**借据**的情况：放款日、到期日、余额、还款状态
- 有没有**逾期**
- **还款计划**执行得怎么样
- **担保方式**：信用、保证、抵押、质押

**几个必须分清的概念**：

| 概念 | 通俗解释 |
|---|---|
| **授信** | 银行批准给你的**额度上限**。给了额度 ≠ 借了钱 |
| **用信 / 提款** | 你实际从这个额度里**借出来的钱** |
| **借据** | **每一笔**放款的凭证。借三次，就有三张借据 |
| **贷款余额** | 还没还掉的本金 |
| **敞口** | 银行真正暴露在风险里的那部分（余额减去担保能覆盖的） |
| **结清 / 展期 / 逾期** | 正常还完 / 到期还不上申请延期 / 没按期还 |

> 🔴 **业务逻辑**：授信额度用没用完、用得快不快，本身就是信号。
> 授信给了 5000 万，一年只用了 200 万——可能是客户不需要，也可能是客户在别处借不到了；
> 授信 5000 万，三个月用满——要问为什么突然这么缺钱。

### 四、本次检查开展情况

**查什么**：

| 事项 | 说明 |
|---|---|
| **现场打卡** | 客户经理有没有**真的去现场**？时间、地点、GPS/照片 |
| **批复后续管理要求落实情况** | 授信批复时提出的管理要求（如"每季提供财报""追加抵押""账户监管"），**逐条看落没落实** |
| **单项检查任务** | 行里单独下发的检查任务完成没有 |
| **特定贷款的检查** | 固定资产贷款、房地产开发贷款、经营性物业贷、厂房贷等**专项贷款**有专门的检查要求 |
| **上一次报告揭示的风险** | 上次发现的风险，这次还在不在 |

> 🔴 **业务逻辑**：**批复要求是"贷后检查的作业本"**。
> 审批会上加的条件（"必须每月提供账户流水""必须追加保证人"）不是建议，是**放款的前提条件**。
> 有一条没落实，本身就是问题，必须写进报告。

**特定贷款为什么要单独检查**：固定资产贷款、房地产开发贷款这类，资金是跟着**项目进度**走的（工程完成多少、放多少款），检查要看：
- 项目进度和放款进度匹配吗
- 资金是不是真的用在项目上
- 项目卖得怎么样（房开贷看销售回款）
- 项目类还要看土地、规划、施工许可等合规手续

### 五、财务指标变化和潜在风险

**查什么**（这是最厚重的一章）：

先看三个"元信息"：
1. **最新报表期数**——用的是几月的报表？太旧的报表没意义（比如 10 月还在用 3 月的报表）
2. **报表审计情况**——有没有经过审计？审计意见是什么？（未审计的报表可信度低）
3. **报表并表情况**——合并报表还是母公司报表？口径不同，数字不能直接比

再看八个重点指标：

| 指标 | 看什么 | 风险含义 |
|---|---|---|
| **营业收入** | 规模 + 同比变化 | 营收快速下滑 = 生意变差 |
| **净利润** | 盈亏 + 变化 | 由盈转亏是最直接的恶化信号 |
| **销售利率、净利率** | 赚钱能力 | 毛利率下降 = 议价能力/成本控制变差 |
| **实收资本** | 股东真金白银投了多少 | 实收资本异常（抽逃、虚高）是诚信问题 |
| **应收账款和其他应收款** | 占比 + 增速 | 占比过高 = 钱收不回来、可能是关联方占款；**"其他应收款"尤其可疑** |
| **资产负债率** | 杠杆水平 | 偏离度高 = 负债过重或数据存疑 |
| **重要负债科目** | 借款结构 | 短期借款激增 = 短期偿付压力大 |
| **其他风险** | 综合判断 | —— |

**三个高频风险点**：

1. **营收和纳税对不上**
   财报说营收 2 亿，税务申报销售额只有 5000 万——**税务数据难造假，财报容易粉饰**。差异大就是信号。

2. **应收账款/存货周转天数延长**
   收钱变慢了、货压在仓库里卖不动了。这通常**比营收下滑更早出现**，是先行指标。

3. **报表真实性**
   银行还会拿**税务侧财务数据**和**企业自己提供的财报**做交叉验证，两边对不上就要打个问号。

> 🔴 **业务洞察（能说出来很加分）**：银行系统里同时保留"企业提供的财报"和"税务申报数据"，
> **不是为了存两份，是为了互相验证**。财报是可以粉饰的，税是真金白银报的。

### 六、征信情况和潜在风险

**1. 什么是征信报告**

企业征信报告是**人民银行征信中心**出具的、汇总了这家企业在**所有金融机构**的授信、负债、担保、逾期、查询记录的报告。

**它是银行最信任的外部数据**——因为数据是全国金融机构报送的，企业没法自己美化。

**2. 征信报告看什么**

| 维度 | 看什么 |
|---|---|
| **征信查询时间** | 报告是什么时候查的？**有没有在有效期内**（通常要求是近期查询） |
| **未结清负债** | 在多少家机构有授信、总余额多少 |
| **债务结构** | 短期借款、中长期借款、票据、信用证、保函……分别多少 |
| **对外担保** | 替别人担保了多少（这是**或有负债**，别人还不上就要它还） |
| **五级分类** | 正常 / 关注 / 次级 / 可疑 / 损失 —— **"关注"及以下就要警惕** |
| **逾期记录** | 有没有逾期、逾期多少 |
| **查询记录** | 谁查过、查了多少次 |

**3. 征信怎么看"异常"**（这是重点）

| 异常表现 | 为什么是风险 |
|---|---|
| **征信查询次数突然很多** | 短时间内被很多机构查询 = 到处申请贷款 = **资金饥渴**，通常伴随资金链紧张 |
| **新增非银机构借款** | 小贷、保理、融资租赁等**非银机构利率高**，说明客户已经从银行借不到了 |
| **融资机构过于分散** | 在十几家机构各借一点 = 很难形成稳定合作关系，一家抽贷就崩 |
| **存在高利率借款** | 融资成本远超同行 = 资金紧张到不计成本 |
| **对外担保金额大** | 或有负债随时可能变成真负债 |
| **流贷余额异常变化** | 短期借款突然大幅增加或减少，都要解释 |
| **征信报告不在有效期内** | 检查依据过时，"没发现问题"其实等于"没看" |

**4. 征信和财务的交叉解读（本项目的核心设计）**

征信报告记的是**金融机构报的负债**，财报记的是**企业自己账上的负债**。两者天然会有差异：

- 财报上短期借款 2000 万，征信上短期未结清只有 300 万 → 企业可能低估了负债，或者征信更新滞后
- 反过来，征信上有大额借款但财报没体现 → 可能是表外负债、或者财报不完整

**差异本身不是结论，但差异必须解释。** 这就是报告里"债务情况"这一节的价值。

> 🔴 **业务概念：一期一行**
> 征信数据、财务数据都是**按时间点/期间**来的（这季度、上季度、上年、授信时）。
> 检查时必须**看对期**——拿去年的数据说今年的风险，等于没检查。

### 七、资金疑似回流或用途异常

**1. 贷款资金为什么要盯**

监管反复强调：**贷款资金必须按约定用途使用**。流动资金贷款拿去做固定资产投资、拿去还股东借款、拿去炒股买房，都是违规。

**2. 受托支付是什么**

按监管要求，符合条件的大额贷款要**采用受托支付**——银行**不把钱打到借款人账户**，而是**直接打给借款人的交易对手**（比如供应商）。

目的很直白：**钱根本没经过借款人手里，就没法挪用**。

**3. 三个典型异常**

| 异常 | 业务含义 |
|---|---|
| **疑似资金回流** | 钱付给供应商后，转一圈又回到借款人自己或关联方账户 —— 典型的**虚构交易套取贷款** |
| **股东借款未归还** | 贷款资金被用于归还股东借款 —— 钱没进经营性用途，**等于股东从银行套现** |
| **受托支付异常** | 该受托支付没做、或支付对象和合同对不上 |

> 🔴 **业务逻辑**：资金流向是**最硬的证据**。企业可以说谎、报表可以粉饰，
> 但**钱从谁的账户到谁的账户**很难造假。

### 八、潜在合规风险关注点

**查什么**：监管明令禁止或重点关注的事项，比如：
- 贷款用途违反规定（流贷买地、买股票、理财）
- 资金流入房地产、股市等限制领域
- 关联交易未披露
- 违规向关系人发放贷款
- 未落实监管专项要求（如房地产贷款集中度、经营贷违规入楼市等）

> 这一章偏"合规视角"，是给内审、监管检查用的。

### 九、结算情况和潜在风险

**核心逻辑**：**"你的业务是不是真的在我这儿做"**。

银行放贷款，一部分目的是**获取结算业务**（存款、中间业务）。如果一个客户在我们这儿借了 5000 万，但**结算账户常年没钱、流水很少**，那说明：

- 它可能只是**把这里当提款机**，真正的业务往来在别的银行
- 或者它**经营确实萎缩了**（没业务就没流水）

**三个查点**：

| 查点 | 看什么 | 风险信号 |
|---|---|---|
| **结算账户与资产** | 账户余额、日均存款、冻结金额、监管标识 | 日均存款极低、账户被冻结 |
| **交易对手情况** | 主要收付款对象、前十大收付款方 | **交易对手异常**（突然换成陌生公司）、交易集中度过高 |
| **代发业务** | 有没有通过我行代发工资、规模变化 | 代发人数/金额骤降 = **可能在裁员、经营萎缩** |

**几个"侧写型"信号**（非常有说服力）：

- **电费收入异常**：电费是制造业最硬的开工证据。电费骤降 = 减产停产。
- **物业收入异常**：经营性物业贷看租金收入，租金下降 = 物业空置。
- **结算与经营不匹配**：报表说营收 5 亿，银行流水只有 300 万 —— 对不上。

> 🔴 **业务洞察**：这类"侧写数据"的价值在于**很难作假**。
> 报表可以编，但电费发票、代发工资名单、结算流水是要真金白银发生的。

### 十、地方征信和潜在风险

地方征信（地方征信平台/地方融资信用服务平台）是**省级/市级政府搭建的信用信息平台**，会汇聚：
- 水电燃气、社保、公积金
- 行政处罚、司法涉诉
- 纳税、不动产
- 地方金融监管信息

**价值**：补足人行征信覆盖不到的地方性信息，尤其对小微企业、地方企业很有用。

### 十一、预警信息和潜在风险

**查三块**：

1. **预警任务及预警信号**
   - 行内预警系统给这个客户发过哪些预警信号
   - 预警编号、风险原因、风险等级、当前状态（已处理/待处理）
   - **有没有没处理的预警**——这是大问题

2. **风险归因模型分析**
   由行内/外部模型给出的风险归因（为什么给你打高风险标签）

3. **行业变化分析**
   客户所在**行业**的宏观变化。为什么重要？——**一家企业再健康，行业塌了也扛不住**（比如教培、房地产、光伏产能过剩）

> 🔴 **业务概念：舆情**
> 重大负面舆情也是预警的一类，包括：司法涉诉、被执行、失信、行政处罚、媒体负面报道、
> 股东/实控人的负面信息。
> **注意**：舆情要**双主体**看——不仅看借款人，还要看**股东**（股东出事，公司跟着遭殃）。

### 十二、担保情况和潜在风险

**担保分两大类**：
- **物的担保**：抵押（不动产等）、质押（股权、存单、应收账款等）
- **人的担保**：保证（担保人承诺替它还钱）

#### 12.1 抵押物（物的担保）

**查什么**：

| 查点 | 业务含义 |
|---|---|
| **评估价值** | 抵押物值多少钱？评估是否过期？ |
| **抵押率** | 贷款额 ÷ 评估值。抵押率越高，安全垫越薄 |
| **抵押顺位** | 我们排第几受偿？（**一押/二押差别巨大**：一押拿走剩下的，二押才轮到） |
| **他项权利** | 抵押登记情况（办了登记才算数） |
| **限制权利** | **有没有被查封、冻结**——一旦查封，处置权受限，是重大风险 |
| **多次抵押** | 同一个物抵给多家机构 = 变相放大杠杆 |

> 🔴 **业务概念：抵押顺位**
> 同一个房子抵给两家银行：A 银行是一押，B 银行是二押。
> 拍卖 100 万，A 银行债权 80 万 → A 拿走 80 万，B 只剩 20 万可拿。
> 所以银行做二押时，**要么抵押率压得很低，要么直接不做**。

#### 12.2 担保人（人的担保）

**核心：担保人自己的credit值不值钱。** 所以要看担保人的**征信**：

- 征信查询时间（在有效期内吗）
- 征信情况（负债、对外担保、逾期、五级分类）
- 债务情况（负债结构）
- 征信查询次数（是否异常频繁）
- 其他风险

**担保人分两类**：
- **企业担保人**（法人）——如母公司、关联公司、担保公司
- **个人担保人**（自然人）——通常是**实际控制人/股东本人**

**个人担保人的特别注意点**：
- 个人负债（房贷、经营贷、信用卡）
- 个人对外担保
- **个人征信查询次数**
- 有些模型还会看实控人的**学历/背景**（学历低+行业复杂 = 风险加分项）

> 🔴 **业务逻辑**：中小企业贷款，**法人担保常常是"形式担保"**（同一个老板名下多家公司互保，等于没担保）。
> 所以行里才要求**实际控制人个人连带担保**——这才是有真实约束力的。

## 第三部分 · 必懂的核心业务概念（集中讲透）

### 3.1 授信 / 用信 / 借据 / 敞口

```
授信额度 5000 万  ← 银行批准的"上限"
   ├─ 已用 3000 万  ← 用信
   │    ├─ 借据1：1000 万（2026-03 放款，2027-03 到期）
   │    ├─ 借据2：1200 万
   │    └─ 借据3： 800 万
   └─ 未用 2000 万  ← 敞口/可用额度
```

- **授信**是"额度"，**用信**是"实际借的钱"，**借据**是"每一笔的凭证"。
- **敞口**：银行真实暴露的风险金额（一般 = 余额 − 担保能覆盖的部分）。

### 3.2 五级分类与不良

| 等级 | 通俗理解 | 是否不良 |
|---|---|---|
| **正常** | 按时还款没问题 | 否 |
| **关注** | 有潜在不利因素，但目前还能还 | 否 |
| **次级** | 还款能力出现明显问题 | ✅ 是 |
| **可疑** | 肯定要损失一部分 | ✅ 是 |
| **损失** | 基本收不回来了 | ✅ 是 |

**记忆点：不良 = 次级 + 可疑 + 损失（后三类）。**

**为什么重要**：五级分类直接决定银行**要计提多少减值准备**、**利润受多大影响**、**监管指标好不好看**。所以一旦从"正常"掉到"关注"，全行都紧张。

### 3.3 逾期与账龄

| 逾期时长 | 常见叫法 |
|---|---|
| 1 个月以内 | M1 |
| 1-2 个月 | M2 |
| 2-3 个月 | M3 |
| …… | 以此类推 |

一般 **逾期超过 90 天（M3+）** 就会被归为不良。逾期时间越长，收回概率越低。

### 3.4 "授信时" vs "最新"

贷后检查里到处出现这两个词：

- **授信时**：当初批贷款那一刻的状态（当时的股权、当时的财报、当时的实控人）
- **最新**：现在的最新状态

**为什么要比**：贷后检查的本质就是**找变化**。
- 授信时是张三当实控人，现在变成李四了 → 风险
- 授信时营收 1 亿，现在 3000 万 → 风险
- 授信时股东是国企，现在国企退出了 → 风险

> 🔴 **一句话**：**贷后检查就是"授信时 vs 现在"的差异分析。**

### 3.5 实际控制人 / 实际受益人 / 股东

| 概念 | 通俗解释 |
|---|---|
| **股东** | 工商登记的持股人（可能是公司，也可能是个人） |
| **实际控制人** | 真正能决定这家公司命运的人（可能通过多层股权间接控制） |
| **实际受益人（受益所有人）** | 最终真正享有收益的自然人（穿透股权后的最终自然人） |

**为什么三者要分清**：股权可以层层嵌套、找人代持，工商登记的股东看起来是一家投资公司，穿透下去才发现在某个人手里。**反洗钱、反逃废债都要求穿透到自然人。**

### 3.6 关联方与关联交易

- **关联方**：与借款人有控制关系、共同控制、重大影响关系的企业或个人（母公司、子公司、兄弟公司、实控人控制的其他公司）
- **关联交易**：与关联方之间的交易

**风险点**：
- 通过关联交易**虚增收入**（左手卖右手）
- 通过关联方**套取贷款资金**（钱转给关联方，绕回老板口袋）
- 关联方出事**连带影响**（担保链条、资金链条）

### 3.7 国有企业 / 假冒国企

- **国有企业**：国有资本控股或实际控制的企业。国企背景通常意味着更强的信用支持。
- **假冒国企**：**冒用国有企业名义**开展经营、宣传、融资的企业。这是监管重点打击对象——因为它利用"国企"两个字骗取信任和融资便利。

**识别方式**：比对国资委公布的央企/国企名录、股权穿透、注册信息。

### 3.8 受托支付 / 资金回流

已在前文第七节讲过，这里补一句核心：

> **受托支付 = 防挪用。资金回流 = 挪用的证据。**

### 3.9 征信 / 外数 / 地方征信——三种数据来源的区别

| 数据源 | 谁提供 | 特点 |
|---|---|---|
| **人行征信** | 人民银行征信中心 | **最权威**，全国金融机构报送，企业无法美化。查负债、担保、逾期、查询记录 |
| **外数（第三方工商数据）** | 商业数据服务商（工商/司法/舆情数据） | **覆盖广、更新快**，查工商变更、股权穿透、实控人、关联企业、司法涉诉、舆情 |
| **地方征信** | 地方政府信用平台 | 补足地方性信息（水电、社保、行政处罚、不动产） |
| **行内数据** | 银行自己的系统 | 授信、用信、借据、结算、代发、抵押——**只有银行自己知道的信息** |

**业务上的配合逻辑**：
- 行内数据看"我们和它的关系"
- 人行征信看"它和其他金融机构的关系"
- 外数/地方征信看"它在社会上的全貌"

三者交叉，才能拼出一个完整画像。

## 第四部分 · 风险信号大全（48 条，讲人话）

> 这些是系统里配置的**风险判断规则**。每条规则的逻辑都是：**数据满足某个条件 → 命中 → 提示风险**。
> 下面按主题归成 6 组，每条说明"为什么这是风险"。

### A 组 · 主体与股权类（5 条）

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 1 | **工商受益人和系统实控人不一致** | 工商口径和银行系统记录对不上，说明**信息失真**或**客户经理未更新**，控制权可能已变 |
| 2 | **国有股东出资比例降低** | 国资退出 = 隐性背书减弱，需要重新评估还款保障 |
| 3 | **重要股东变更** | 授信期间股东大换血，原有的合作基础/还款逻辑可能不存在了；也可能是股东在**抽身跑路** |
| 4 | **疑似假国资** | 冒用国企名义 = **诚信问题**，且往往伴随过度包装融资 |
| 5 | **重大负面舆情** | 司法涉诉、被执行、失信、行政处罚、媒体负面——直接影响经营和还款 |

### B 组 · 财务类（11 条）

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 6 | **营收快速下降** | 生意变差最直接的证据 |
| 7 | **纳税申报销售额异常** | 税务数据和财报/历史对不上，可能**虚增收入**或**隐瞒经营** |
| 8 | **净利润异常** | 由盈转亏、利润剧烈波动都是问题 |
| 9 | **实收资本异常** | 股东真金白银有没有到位；抽逃出资是诚信问题 |
| 10 | **应收账款/其他应收款占比高** | 钱收不回来；**"其他应收款"尤其可疑**（往往是关联方占用资金） |
| 11 | **资产负债率偏离度高** | 负债过重，或数据本身存疑 |
| 12 | **融资过度扩张** | 借钱速度远超经营规模增长 = 加杠杆豪赌 |
| 13 | **应收账款周转天数延长** | 收钱变慢，**比营收下滑更早出现**（先行指标） |
| 14 | **存货周转天数延长** | 货卖不动了，积压占资金 |
| 15 | **应收账款/存货增速异常** | 应收、存货增速远超营收增速 = 可能在**虚增收入**（货没真卖出去） |
| 16 | **报表真实性存疑** | 财报与税务/征信数据交叉不上 |

### C 组 · 征信与债务类（7 条 × 2 个主体）

> 企业和担保人**都要查**，所以这类规则会出现两遍。

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 17 | **征信查询不在有效期内** | 检查依据过时，"没发现问题"= "根本没看" |
| 18 | **征信异常** | 五级分类降级、逾期出现、被关注 |
| 19 | **债务异常** | 未结清余额、债务结构出现异常变化 |
| 20 | **非银债务** | 从小贷、保理、融资租赁借钱 = 银行渠道借不到了 |
| 21 | **银租融资过于分散** | 在太多机构各借一点，一家抽贷就崩 |
| 22 | **存在非银机构较高利率借款** | 融资成本不计代价 = 资金极度紧张 |
| 23 | **流贷余额变化** | 短期借款激增/骤降都要解释 |

### D 组 · 资金用途类（3 条）

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 24 | **疑似资金回流未被认定** | 贷款资金绕回借款人或关联方 = 涉嫌**虚构交易套取贷款** |
| 25 | **股东借款未归还** | 贷款资金被用来还股东借款 = **股东变相从银行套现** |
| 26 | **受托支付异常** | 该受托支付没做、或支付对象与合同不符 = 挪用风险 |

### E 组 · 经营佐证类（7 条）

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 27 | **结算与经营不匹配** | 报表说营收几个亿，银行流水只有几百万 → 业务不真实，或没在这儿做 |
| 28 | **代发工资异常** | 代发人数/金额骤降 = 在**裁员**、经营萎缩 |
| 29 | **物业收入异常** | 经营性物业租金下降 = 物业空置（针对经营性物业贷） |
| 30 | **电费收入异常** | 制造业最硬的开工证据；电费骤降 = **减产停产** |
| 31 | **交易对象异常** | 主要交易对手突然换成陌生公司、或高度集中 = 交易真实性存疑 |
| 32 | **潜在合规风险关注点** | 触碰监管红线的事项 |
| 33 | **行业变化分析** | 行业整体下行，再健康的企业也扛不住 |

### F 组 · 担保类（15 条）

| # | 风险信号 | 为什么是风险 |
|---|---|---|
| 34 | **抵押物多次抵押** | 同一个物抵给多家机构 = 变相放大杠杆，安全垫被摊薄 |
| 35 | **存在限制权利** | 抵押物被**查封/冻结** = 处置权受限，担保形同虚设 |
| 36 | **担保人征信查询不在有效期** | 同上，检查依据过时 |
| 37 | **担保人征信异常** | 担保人自己都自身难保，担保没意义 |
| 38 | **担保人债务异常** | 担保人负债过重 |
| 39 | **担保人非银债务** | 同上逻辑 |
| 40 | **银租融资过于分散**（担保人） | 同上 |
| 41 | **担保人存在非银机构较高利率借款** | 同上 |
| 42 | **担保人流贷余额变化** | 同上 |
| 43 | **对外担保金额大** | 或有负债随时变真负债 |
| 44 | **担保人征信查询异常** | 查询频繁 = 资金饥渴 |
| 45 | **担保人非银债务（个人）** | 个人对外借高息 |
| 46 | **实控人学历低** | 部分风险模型把"实控人背景弱 + 行业复杂"作为风险加分项 |
| 47 | **个人担保人征信查询次数** | 同上 |
| 48 | **担保人其他风险** | 兜底类 |

> **说明（怎么数这 48 条）**：A 组 5 + B 组 11 + C 组 7 + D 组 3 + E 组 7 + F 组 15 = 48 条。
> 你会注意到"征信查询不在有效期内""征信异常""债务异常""非银债务""银租融资过于分散""流贷余额变化"这几条**出现了两遍**——
> 不是重复，而是因为**借款人和担保人两个主体都要各自查一遍**（分别对应报告第六章和第十二章）。
> 去重后真正独立的**检查事项约 20 项**，这才是"贷后检查要看什么"的真实清单。

## 第五部分 · 四个真实场景串讲

> 把上面的知识串起来用。这四段能讲出来，说明真懂了。

### 场景一：一家制造业客户的"温水煮青蛙"

**表面**：营收 1.2 亿，同比只降了 8%，看起来还稳。

**系统挑出来的信号**：
- 存货周转天数从 65 天 → 110 天（**货开始积压**）
- 应收账款周转天数从 90 天 → 145 天（**钱开始收不回来**）
- 电费同比下降 35%（**开工明显不足**）
- 代发工资人数减少 20%（**在裁员**）
- 银行存款日均从 800 万跌到 120 万（**结算萎缩**）

**业务判断**：营收只降 8% 是**假象**（可能靠赊销冲出来的），真实的经营已经在收缩。**周转天数、电费、代发是最先动的先行指标。**

> 这就是为什么贷后检查不能只看"营收有没有降"。

### 场景二：资金链紧张的典型轨迹

**顺序很重要**：
1. 经营现金流恶化 → 开始在其他银行申请贷款
2. **征信查询次数暴增**（到处申请）
3. 银行渠道借不到了 → **转向非银机构**（小贷、保理、融资租赁）
4. **融资成本飙升**（愿意付高息）
5. 开始**挪用我们的贷款**（资金回流、还股东借款）
6. 逾期出现

**业务判断**：**征信查询次数是最早的信号**，比逾期早好几个月。看到查询次数暴增就该警觉，而不是等逾期。

### 场景三：控制权悄悄变了

**表面**：企业名称、业务都没变，还款也正常。

**系统挑出来的信号**：
- 工商登记的实际受益人变了（原来穿透到张老板，现在穿透到一家投资公司）
- 系统里记录的实际控制人还是张老板（**客户经理没更新**）
- 持股 35% 的国有股东退出了
- 短时间内**重要股东变更**两次

**业务判断**：控制权可能已经悄悄转移。**新股东是谁？为什么要接盘？原来的还款意愿还成立吗？** 这必须现场核实——这就是"工商口径 vs 系统口径"差异的价值：**不是系统错了，而是差异暴露了没人跟进的变更。**

### 场景四：贷款资金去哪了

**可疑链路**：
1. 银行贷款 2000 万，采用受托支付，打给"某某贸易公司"
2. 几天后，该贸易公司把钱转到另一家公司
3. 再转一手，回到**借款人股东的个人账户**
4. 同期，借款人账上"股东借款"科目**大幅减少**

**业务判断**：典型的**虚构贸易背景套取贷款 + 资金回流归还股东借款**。这是监管重点打击的行为，一旦认定，不仅提前收贷，还可能涉及刑责。

**为什么能发现**：因为**资金流向是最硬的证据**——企业可以说谎、报表可以粉饰，但钱的路径很难造假。

## 第七部分 · 新人最容易搞错的 8 件事

| # | 误区 | 正确理解 |
|---|---|---|
| 1 | 给了授信就等于借了钱 | 授信是额度，用信才是实际借款 |
| 2 | 五级分类"关注"不算不良，可以不管 | **"关注"是预警线**，从这级开始就要计提、就要盯 |

| 4 | 抵押物在就行，不用管顺位 | **二押和一押完全不是一回事**，二押可能什么都拿不到 |
| 5 | 有担保人就安全 | 法人互保常常是"形式担保"；要**实际控制人个人连带**才有效 |

| 7 | 上次检查提的问题写进报告就算完成了 | 要看**落实结果**，这是监管最爱查的闭环 |
| 8 | 工商信息和系统信息不一样，改系统就行 | **差异本身就是风险信号**，要核实"为什么不一样" |

# 附录 A · 人行企业征信报告——里面到底有什么

> 很多人以为"征信报告"就是一张分数单。其实它是一本**结构化的账本**，全国所有金融机构都在往里记你以为只有自己知道的账。
> 下面按报告的自然结构讲——**这就是"征信报告怎么看"的说明书**。

## A.1 报告开头：先看全局

| 段落 | 里面有什么 | 一看就懂的信号 |
|---|---|---|
| **报告基本信息** | 报告编号、生成时间 | **报告什么时候出的？** 太旧 = 检查依据过时 |
| **信贷交易提示信息** | 首次交易年份、累计发生笔数、当前未结清笔数、贷款余额、担保余额 | **一眼看全局**：跟多少家机构有往来、总共欠多少 |

## A.2 中段：逐笔看负债

| 段落 | 里面有什么 |
|---|---|
| **授信协议信息** | 各机构批准了多少额度、什么期限 |
| **借贷账户基本信息** | **每个账户**：起始日、管理机构（哪家银行）、机构类型、账户状态、贷款种类、到期日 |
| **还款表现信息** | **逐月还款记录 + 五级分类 + 最近还款日 + 余额** ← 最重要 |
| **特定交易信息** | 展期、重组、以资抵债等特殊处理 |

> 🔴 **"还款表现"是征信报告里信息密度最高的一段**：
> 它不只告诉你"有没有逾期"，还告诉你**这个账户被归为哪一类**（正常/关注/次级/可疑/损失）、**每个月什么时候还的**。
> 连续 24 个月的还款记录，能看出这家企业的还款习惯是"一直很稳"还是"经常踩着点挤牙膏"。

## A.3 担保段：别人欠的钱也可能算在你头上

| 段落 | 里面有什么 |
|---|---|
| **担保账户基本信息** | 你们家给谁担保了、担保多久 |
| **在保责任信息** | 担保还在身上的余额（**或有负债**） |
| **未结清担保交易汇总信息** | 按机构汇总的担保余额 |

> 🔴 **业务逻辑**：担保余额不是你的负债，但**只要被担保人还不上，立刻变成你的负债**。
> 所以贷后检查看到"对外担保金额大"，一定要看被担保方是谁、经营怎么样。

## A.4 汇总段：把明细算成数字

| 段落 | 里面有什么 |
|---|---|
| **未结清/结清借贷分类汇总** | 按**五级分类**汇总的余额（正常多少、关注多少、次级多少…） |
| **未结清借贷交易汇总** | **逾期总额**等汇总指标 |
| **欠息信息** | 欠了多少利息（**欠息往往比逾期更早出现**） |
| **负债历史汇总** | 负债的**历史趋势**（看是在扩张还是在收缩） |

## A.5 最容易被忽略的一段：相关还款责任

人行征信里有一类记录叫 **"相关还款责任"**，指的是**你替别人承担的还款责任**，分三种：

| 类型 | 说明 |
|---|---|
| **相关还款责任·借贷账户**（不含贴现） | 你作为保证人，替别人背的**贷款**责任 |
| **相关还款责任·贴现账户** | 替别人背的**票据贴现**责任 |
| **相关还款责任·担保账户** | 替别人背的**其他担保**责任 |

每类还会**分机构汇总**（你在哪些机构有多少这类责任）。

> 🔴 **为什么这段重要**：企业自己在财报里通常**不会体现对外担保**，但从征信的这段能看全。
> 这就是为什么"征信负债 vs 财报负债"经常对不上——**财报没写，征信写了**。

## A.6 读征信报告的 6 个动作（实操）

1. **看时间**——报告是不是近期的？多旧算旧？按行内要求（通常 1 个月内）
2. **看机构数**——跟几家机构有往来？（过于分散 = 不稳）
3. **看五级分类**——有没有"关注"及以下？占比多少？
4. **看逾期和欠息**——有没有、多长、多少钱
5. **看担保**——对外担保多少、担保对象是谁
6. **看查询记录**——最近谁查过、查了几次（**别漏了这条，它是最早的信号**）

# 附录 B · 银行能看到的企业外部数据全景

> 银行判断一家企业，不只靠它自己交材料。下面这张表是**行外数据渠道的全景清单**，
> 它们和征信配合，拼出企业的完整画像。

## B.1 工商与股权类（看"这家公司是谁的、还是不是原来那个人"）

| 数据 | 能看出什么 |
|---|---|
| **企业工商信息** | 名称、注册资本、实缴、法人、经营范围、成立时间、经营状态 |
| **组织机构信息** | 组织架构、分支机构 |
| **企业股东信息** | 谁持股、持股多少 |
| **实际控制人** | 真正说了算的人（穿透后） |
| **最终受益人** | 最终拿到收益的自然人（反洗钱关键） |
| **集团关联图谱** | 这家公司在整个集团里的位置、关联企业有哪些 |
| **集团成员信息** | 集团内其他成员的工商信息 |
| **上市公司基础信息** | 是不是上市公司、什么板块 |

## B.2 司法与合规类（看"有没有官司、有没有赖账"）

| 数据 | 能看出什么 |
|---|---|
| **司法公告（涉诉）** | 有没有被起诉、被公告 |
| **被执行人** | 有没有被法院强制执行 |
| **失信被执行人** | 有没有被列入"老赖"名单 ← **这条最严重** |

## B.3 税务类（看"经营是不是真的"）—— 五个异常项

| 数据 | 能看出什么 |
|---|---|
| **税务违法** | 有没有税务违法行为 |
| **税务非正常户** | 有没有被认定为"非正常户" ← **接近停摆的信号** |
| **纳税催报** | 有没有被催报（不按期申报） |
| **责令限期改正** | 有没有被责令整改 |
| **停业注销信息** | 有没有停业、注销 |

> 🔴 **这五项合起来是一套"企业体检异常项"**。
> 单独一项可能只是疏忽，**同时出现两三项，基本可以判断企业已经不正常经营了**。
> 税务数据由政府掌握，**企业没法美化**，这是它比财报可信的原因。

## B.4 融资与债券类（看"它在外面还借了什么钱"）

| 数据 | 能看出什么 |
|---|---|
| **企业融资信息** | 外部融资租赁、保理等融资记录 |
| **未结清发债信息** | 有没有发债、还有多少没还 ← **发债企业信息透明度要求高，是重要参考** |
| **机构信用评级** | 外部机构给的信用评级 |

## B.5 国资与监管类（看"有没有国企背景"）

| 数据 | 能看出什么 |
|---|---|
| **国资委数据** | 是不是真国企、在不在国资委名录 |
| **绩效标准值** | 国资委发布的行业绩效标杆值（用来对比"这个企业算好还是差"） |

> 🔴 **用途**：一是识别**真假国企**（假冒国企是监管重点），
> 二是拿**行业标杆值**做横向比较——"这家企业资产负债率 68%"本身没意义，
> 但"同行平均 55%"就能看出它偏高。

## B.6 外部数据的使用原则

| 原则 | 说明 |
|---|---|
| **交叉验证** | 工商说一套、系统记一套、企业报一套 → 差异要核实 |
| **先后顺序** | 司法/税务异常 → 往往早于财务恶化出现 |
| **看主体也要看股东** | 股东出事，公司跟着遭殃 |
| **看当期也要看趋势** | 单点数据没意义，趋势才有意义 |

# 附录 C · 财务报表主要科目速查

> 银行看财报，**不是通读，是挑重点看**。这份速查表按"资产负债表 / 利润表 / 现金流量表"三张表列出主要科目，
> 并标出银行最关注的项。

## C.1 资产负债表（某一时点的"家底"）

### 资产端（钱变成了什么）

| 大类 | 主要科目 |
|---|---|
| **流动资产** | 货币资金、应收账款、应收票据、预付款项、其他应收款、存货、合同资产、一年内到期的非流动资产 |
| **非流动资产** | 长期应收款、长期股权投资、其他权益工具投资、投资性房地产、固定资产、在建工程、无形资产、商誉、长期待摊费用、递延所得税资产 |

> 🔴 **银行重点盯**：
> - **应收账款 / 其他应收款**——占比高说明钱收不回来；**"其他应收款"尤其可疑**（常是关联方占款）
> - **存货**——积压占资金
> - **商誉**——并购留下的，减值会直接冲击利润
> - **在建工程**——长期不转固可能是虚增资产

### 负债端（欠了谁的钱）

| 大类 | 主要科目 |
|---|---|
| **流动负债** | 短期借款、应付票据、应付账款、预收账款、合同负债、应付职工薪酬、应交税费、其他应付款、一年内到期的非流动负债 |
| **非流动负债** | 长期借款、应付债券（含优先股、永续债）、长期应付款、预计负债、递延收益、递延所得税负债 |

> 🔴 **银行重点盯**：
> - **短期借款 vs 长期借款的结构**——短期多说明**偿付压力集中**
> - **一年内到期的非流动负债**——"明年要还多少"就靠它加短期借款
> - **其他应付款**——常藏着股东借款、关联方资金往来
> - **预计负债**——潜在官司、担保代偿的预提

### 所有者权益（股东的钱）

实收资本（股本）、资本公积、其他综合收益、盈余公积、**一般风险准备**、未分配利润、少数股东权益

> 🔴 **实收资本**：注册资本 1 亿但实收只有 100 万，说明股东**没真掏钱**。
> **未分配利润为负**（累计亏损）是明显的危险信号。

## C.2 利润表（一段时间的"赚没赚钱"）

| 层级 | 主要科目 |
|---|---|
| **营业总收入** | 营业收入 / 利息收入 / 手续费及佣金收入 / 已赚保费 |
| **减：营业总成本** | 营业成本 / 利息支出 / **税金及附加** / **销售费用** / **管理费用** / **研发费用** / **财务费用** / 资产减值损失 / 信用减值损失 |
| **加：其他** | 公允价值变动损益、投资收益、汇兑损益、资产处置收益、其他收益 |
| **= 营业利润** | |
| **加/减：营业外** | 营业外收入 / 营业外支出 |
| **= 利润总额** | |
| **减：所得税费用** | |
| **= 净利润** | 持续经营净利润 / 终止经营净利润、归母净利润 / 少数股东损益 |

> 🔴 **银行重点盯**：
> - **营业收入同比**——生意规模变没变
> - **毛利率、净利率**——赚钱能力变没变
> - **财务费用**——**财务费用激增 = 融资成本上升 = 资金紧张**
> - **信用减值损失 / 资产减值损失**——有没有大额计提（自己承认资产质量变差）
> - **营业外收入**——靠卖资产、政府补贴撑利润，**主业不行**

## C.3 现金流量表（一段时间"钱的进进出出"）

分三大类，每类都是"流入 − 流出 = 净额"：

| 大类 | 主要科目（流入 / 流出） |
|---|---|
| **一、经营活动** | **销售商品提供劳务收到的现金** / 收到的税费返还；购买商品接受劳务支付的现金 / **支付给职工的现金** / 支付的各项税费 → **经营活动现金流量净额** |
| **二、投资活动** | 收回投资、取得投资收益、处置固定资产收到的现金；购建固定资产、投资支付的现金 → **投资活动现金流量净额** |
| **三、筹资活动** | 取得借款收到的现金；**偿还债务支付的现金**、分配股利支付的现金 → **筹资活动现金流量净额** |

> 🔴 **银行重点盯**：
> - **经营活动现金流净额**——**这是最硬的指标**。利润可以是账面的，经营现金流是真金白银。
>   **"有利润没现金流"** 是典型的风险特征（赚的是白条）。
> - **三大类现金流的组合**，能看出企业在什么状态：

| 组合 | 含义 |
|---|---|
| 经营 +、投资 −、筹资 + | **成长期**：主业在赚钱，还在投，还在借 |
| 经营 +、投资 −、筹资 − | **成熟期/还债期**：靠主业赚钱还债（健康） |
| 经营 −、投资 −、筹资 + | **危险**：主业不产生现金，全靠借钱撑着 ← **最需要警惕** |
| 经营 −、投资 +、筹资 − | **收缩期**：卖资产还债 |

## C.4 一个必须知道的常识：一般企业 vs 金融企业

同一张报表，**一般企业和金融企业的科目完全不同**：

| 表 | 一般企业（制造业等） | 金融企业（银行/保险） |
|---|---|---|
| 资产端 | 存货、固定资产、在建工程 | **发放贷款及垫款、拆出资金、买入返售金融资产、结算备付金** |
| 负债端 | 应付账款、预收账款 | **吸收存款及同业存款、向中央银行借款、拆入资金、卖出回购金融资产款** |
| 收入 | 营业收入 | **利息收入、手续费及佣金收入、已赚保费** |

> 🔴 **为什么要知道这个**：如果一家企业报上来的财报里出现"吸收存款""发放贷款及垫款"，
> 那它**不是普通工商企业**，而是金融机构（或财务公司/小贷/租赁公司）。
> **放款对象的行业属性判断错了，后面所有财务分析都是错的。**

## C.5 报表分析的正确姿势（三句话）

1. **先看结构，再看数字**——先确认"这是谁的报表、什么口径、什么期间"
2. **先看趋势，再看单点**——单点数字没意义，"连续三期怎么变"才有意义
3. **先看现金，再看利润**——利润可以调节，现金流难调节
