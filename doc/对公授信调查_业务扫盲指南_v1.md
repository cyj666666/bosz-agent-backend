# 对公授信调查 · 业务扫盲指南

> **给谁看**：没接触过银行授信业务的人；或者懂贷后、但说不清贷前的人。
> **日期**：2026-10-15

---

## 第一部分 · 授信调查是什么

### 1.1 它在信贷流程的哪一环

| 阶段 | 通俗说法 | 授信调查的位置 |
|---|---|---|
| **贷前** | "要不要借、能借多少" | ✅ **就是这一环** |
| 贷中 | "签合同、放钱" | 落实担保、放款 |
| 贷后 | "借出去以后盯住" | 定期检查、预警 |

**授信调查** = 银行在决定"借不借、借多少"之前，对客户和这笔业务做的**全面调查与评估**，最终形成一份**授信调查报告**，提交审批。

### 1.2 为什么贷前调查比贷后更关键

> **贷前做错了，后面全是补救；贷前做对了，后面才有的可救。**

- 贷后检查是"发现问题、减少损失"
- 贷前调查是"**避免问题发生**"

一笔坏账的根源，**九成能追溯到贷前调查没做透**：没看清实控人、没算准资金需求、没核实项目手续、没查清关联方。

### 1.3 授信调查的四条主线

不管什么产品，调查报告都在回答四个问题：

| 主线 | 回答的问题 |
|---|---|
| **① 借款人是谁** | 主体资格、股权、实控人、经营历史、信用记录 |
| **② 借钱干什么** | 用途是否合规、是否真实、金额是否合理 |
| **③ 靠什么还** | **第一还款来源**（经营现金流）+ **第二还款来源**（担保） |
| **④ 有什么风险** | 经营、财务、法律、行业、关联方风险 + 对策 |

> 🔴 **记住这条**：**任何一笔授信，都必须有明确的第一还款来源。**
> 只靠抵押物的贷款，本质上做的不是信贷业务，是"典当"。

## 第二部分 · 四种授信调查报告

同一家银行，不同产品的调查报告**结构完全不同**。这是最容易被忽略的业务常识。

| 产品 | 报告类型 | 核心关注 |
|---|---|---|
| **对公流动资金贷款** | 公司类客户授信调查报告 | 经营能力、财务、上下游、资金需求 |
| **小微贷款** | 小微企业贷款调查表 | 经营者个人、担保公司、简易财务 |
| **固定资产贷款** | 项目（评估、调查）报告 | **项目本身**：合规手续、投资估算、效益测算 |
| **房地产开发贷款** | 房地产开发贷款授信调查报告 | **楼盘**：销售进度、回笼资金、实控人集团实力 |

### 2.1 对公流动资金贷款调查报告

**典型内容清单**：

| 板块 | 看什么 |
|---|---|
| **封面与申报** | 客户名称、申请金额、期限、品种、用途 |
| **客户基本情况** | 工商信息、经营范围、成立年限、行业、规模 |
| **股权与管理** | 主要股东、实际控制人、经营管理团队 |
| **集团与关联** | 集团信息、参股/实控公司情况 |
| **与我行合作情况** | 已有哪些业务往来、历史合作质量 |
| **信用记录** | 信用等级评定、涉诉信息（限高/失信被执行人）、涉诉公开信息 |
| **经营情况** | 主营业务、盈利模式、产品竞争力、市场份额 |
| **上下游** | 前五大上游客户、前五大下游客户、交易集中度 |
| **财务分析** | 三大报表 + 重点科目 + 账龄 + 存货明细 |
| **资本市场融资** | 上市融资情况、债券发行情况 |
| **申报方案** | 授信额度、分项额度、期限、用途、定价、条件 |
| **资金需求测算** | 算出来"到底需要多少钱" |
| **还款来源** | 第一还款来源（经营现金流）+ 第二还款来源 |
| **担保** | 建议的抵押物/质押物、最高额担保 |
| **调查结论** | 明确意见：同意/不同意、金额、条件 |

### 2.2 小微企业贷款调查表

小微企业（含个体工商户）的特点是**没有规范财务报表**，所以调查方式完全不同：

| 特点 | 调查方式 |
|---|---|
| 报表不规范 | **重实地、重流水**：水电表、工资发放、纳税、银行流水 |
| 企业与老板不分家 | **查经营者个人**：个人及配偶负债、征信、资产 |
| 缺抵押物 | 引进**担保公司**、政府风险补偿基金 |
| 金额小、频次高 | 简化流程、标准化产品 |

**专项内容**：申请信息及贷款用途表、贷款建议表、担保公司信息表、经营主体信用情况（企业+个人）。

### 2.3 固定资产贷款项目评估报告

固贷的特点：**钱跟着项目走，分次放款**。所以调查重点从"企业"转向"**项目**"。

| 板块 | 看什么 |
|---|---|
| **项目基本信息** | 项目名称、建设内容、建设地点、投资规模 |
| **投资人基本信息** | 谁是投资方、实力如何 |
| **项目批准文件** | 项目立项批复 |
| **可研或初步设计批复** | 可行性研究报告是否获批 |
| **四证**（见下节） | 土地、规划、施工许可 |
| **环保批复** | 环评是否通过 |
| **投资估算与融资方案** | 总投资多少、钱从哪来 |
| **项目财务效益测算** | 项目自己能不能赚钱 |
| **贷款偿还能力测算** | 用项目现金流算还本付息能力 |
| **表内外授用信情况** | 银行对这家客户（含集团）的全部敞口 |
| **资本结构表** | 自有资金 vs 借入资金 |

> 🔴 **固定资产贷款的"四证"**（合规底线，缺一不可）：
> ① **土地批复/土地证** ② **建设用地规划许可证** ③ **建设工程规划许可证** ④ **施工许可证**
> 另外还有：项目立项批复、可研批复、**环保批复**。
> **这些手续不全就放款，是信贷业务的红线。** 所以调查报告要逐项核验。

### 2.4 房地产开发贷款调查报告

房开贷是固贷的"特化版"，多了一层**市场风险**：

| 专项内容 | 看什么 |
|---|---|
| **开发楼盘情况** | 楼盘位置、业态、体量、周边配套 |
| **项目建设进度** | 计划进度 vs 目前实施进度 |
| **项目销售进度** | 卖了多少、去化率 |
| **销售回笼资金使用情况** | **卖房的钱去哪儿了** ← 最关键 |
| **实控人控制集团近 3 年营收** | 集团实力兜底能力 |
| **客户可获取的财政补贴、拨款** | 地方政策支持 |

> 🔴 **房开贷的核心逻辑**：**还款来源就是卖房回款**。
> 所以调查的两个命门是：① **这楼盘卖得出去吗**（市场风险）② **卖了的钱有没有被挪用**（资金监管）。
> "销售回笼资金使用情况"这一项，就是在查第②点。

## 第三部分 · 核心业务概念讲透

### 3.1 第一还款来源 vs 第二还款来源

| 概念 | 是什么 | 举例 |
|---|---|---|
| **第一还款来源** | 借款人**正常经营产生的现金流** | 销售收入、项目回款、租金收入 |
| **第二还款来源** | 第一还款来源不足时的**补充** | 抵押物处置、担保人代偿 |

> 🔴 **业务铁律**：
> **一笔贷款必须建立在第一还款来源之上。** 第二还款来源是"保险"，不是"依靠"。
> 调查报告里"还款来源"这一节，**第一还款来源的分析分量应该远重于担保**。
> 如果一份报告的还款来源部分通篇在讲"抵押物足值"，那这份报告是有问题的。

### 3.2 资金需求量测算——到底该借多少？

**不是客户要多少就给多少，而是算出来。**

**通用测算逻辑（流动资金贷款）**：

```
营运资金需求 = 经营规模 × 周转天数 / 365
实际可贷额度 ≈ 营运资金需求 − 自有资金 − 其他渠道融资
```

**要考虑的因素**：

| 因素 | 影响 |
|---|---|
| 销售规模 | 生意越大，铺底资金需求越大 |
| 应收账款周转天数 | 收钱越慢，占用的钱越多 |
| 存货周转天数 | 备货越多，占用的钱越多 |
| 应付账款周转天数 | 能拖供应商的账，反而减少资金需求 |
| **自有资金** | 企业自己必须投入（**不能全靠银行**） |
| **其他融资** | 已经在别处借的，要扣掉，**避免多头过度授信** |

> 🔴 **"过度授信"是贷前最典型的错误**：
> 客户在五家银行各借 5000 万，每家都觉得自己那 5000 万有抵押物兜底——
> 而客户真实的资金需求可能只有 1 亿。**多出来的 1.5 亿，大概率被挪去干别的了。**
> 所以调查报告有一项专门的工作：**"表内外授用信情况"**——把银行对这家客户（含集团）的全部敞口算清楚。

### 3.3 授信额度、分项额度、品种、期限、定价

| 概念 | 含义 |
|---|---|
| **授信额度** | 银行批准的总盘子 |
| **分项额度** | 总盘子下按品种分的子额度（流动资金贷款额度、银承额度、保函额度…） |
| **授信品种** | 具体产品：流动资金贷款、银行承兑汇票、信用证、保函、贸易融资… |
| **授信用途** | 这笔钱的约定用途（采购原材料、支付工程款、置换他行贷款…） |
| **授信期限** | 多久（1 年、3 年、5 年…） |
| **定价** | 利率多少、怎么定（基准加点、LPR 加点等） |

### 3.4 授信条件与管理要求（批复条件）

审批会通过后，会在批复里附加条件，比如：

| 类型 | 举例 |
|---|---|
| **前置条件**（放款前必须落实） | "必须先办妥抵押登记""必须追加实控人连带保证" |
| **持续性要求**（放款后持续满足） | "每季提供财务报表""账户资金监管""销售回款归行不低于 X%" |
| **限制性条款** | "不得新增对外担保""资产负债率不得超过 70%" |

> 🔴 **这是贷前与贷后的连接点**：
> 批复条件是"贷后检查的作业本"。贷后检查第四部分"批复后续管理要求落实情况"，
> 就是逐条回看这里的条件落没落实——**贷前的承诺，贷后要验收**。

### 3.5 客户信用等级评定

银行会用一个**内部评级模型**给客户打等级（通常分 10 级左右，如 AAA~D）。

**评级看什么**：财务指标（盈利、偿债、营运）+ 非财务因素（行业、规模、管理、区域、信用记录）+ 定性判断。

**评级决定什么**：
- 能不能准入（低于某等级直接不受理）
- 额度上限
- 担保方式要求（等级低的必须强担保）
- 定价（等级低利率更高）
- 审批权限（报到哪一级审批）

### 3.6 EVA 测算——这笔贷款划不划算

**EVA（经济增加值）** = 银行做这笔业务赚的钱 − 占用资本的**机会成本**。

**为什么银行要算这个**：一笔贷款名义利差 2%，但占用的风险资本、计提的拨备、管理成本算进去，可能**实际是亏的**。

> 🔴 **业务视角**：所以授信调查不只回答"能不能做"，还要回答"**值不值得做**"。
> EVA 为负的业务，即使风险可控，银行也可能不做——这是**资本约束**下的经营逻辑。

### 3.7 担保安排（贷前就要谈好）

| 类型 | 要点 |
|---|---|
| **抵押** | 抵押物是什么、评估值多少、**抵押率**（贷款额÷评估值）、抵押顺位 |
| **质押** | 质押物（股权/存单/应收账款/存货）、质押率 |
| **保证** | 保证人是谁、代偿能力如何、**是否有连带责任** |
| **最高额担保** | 最高额抵押/保证——在最高债权额内，对**一段时间内连续发生的多笔债务**统一担保（比逐笔办省事） |

**担保安排的业务原则**：
1. **优先实际控制人个人连带保证**（中小企业"法人互保"常是形式担保）
2. **抵押物要求：权属清晰、可处置、易变现、价值稳定**
3. **抵押率留足安全垫**（不动产常见 60%~70%，专用设备更低）
4. **不接受法律禁止抵押的财产**（如公益设施、权属有争议的）

## 第四部分 · 客户尽调到底看什么

### 4.1 看主体：这家公司靠不靠谱

| 看什么 | 要点 |
|---|---|
| **主体资格** | 营业执照、经营状态、年报是否正常报送、有没有经营异常 |
| **成立年限** | 太短（如不满 1 年）风险高；太长要关注是否"僵尸企业" |
| **注册资本与实缴** | **实缴才是真金白银**；虚高注册资本要警惕 |
| **经营范围与主业** | 实际做的和登记的是否一致 |
| **股权与穿透** | 股东是谁、穿透到自然人、有没有代持 |

### 4.2 看人：实际控制人

中小企业授信，**人比企业重要**。

| 看什么 | 要点 |
|---|---|
| 从业经历 | 干了多少年、懂不懂行 |
| 个人信用 | 个人征信、有没有被执行/失信 |
| 个人负债 | 房贷、经营贷、对外担保 |
| 资产实力 | 房产、股权、其他资产（侧面反映实力） |
| 家庭稳定性 | 婚姻状况（涉及财产分割风险） |
| 品行评价 | 有没有赌博、大额消费、频繁更换关联公司等异常行为 |

### 4.3 看经营：生意是不是真的

| 看什么 | 怎么印证 |
|---|---|
| 主营业务与盈利模式 | 靠什么赚钱、赚钱能力如何 |
| 产品竞争力 | 技术、品牌、渠道 |
| 市场份额 | 在行业里什么位置、优劣势 |
| **前五大上下游客户** | **集中度多高**（依赖单一客户 = 风险） |
| **账实相符** | 账上的存货、设备，实地看得到吗 |
| **水电表、工资发放** | 用电量、发工资人数——**最不会骗人的经营证据** |
| 纳税情况 | 与报表营收是否匹配 |

> 🔴 **两个高价值动作**：
> ① **前五大上下游**——如果一家企业 80% 收入来自一个客户，那这个客户的生死就是它的生死。
> ② **水电表 + 工资**——这两样很难造假。工厂说满负荷生产，电费却腰斩？说明在减产。

### 4.4 看财务：报表背后的真相

**除了常规三大报表分析，贷前调查要额外做两件事**：

| 动作 | 目的 |
|---|---|
| **看账龄** | 应收账款账龄结构——超过 1 年的占比多少？（**能看出坏账风险**） |
| **看明细** | 应收账款/应付账款/预付账款**大客户明细**、**存货明细**、**预收账款明细** |
| **交叉验证** | 报税数据 vs 报表数据 vs 银行流水 vs 征信负债 |

> 🔴 **"账龄"比"总额"重要**：
> 应收账款 1 个亿，如果 70% 是 1 年以上的，那这 1 个亿里可能有大半收不回来。
> **只看总额不看账龄，等于没看。**

### 4.5 看合作：客户和我行的关系

| 看什么 | 要点 |
|---|---|
| 已有业务 | 存款、结算、代发、票据…合作深度如何 |
| 合作历史质量 | 有没有逾期、有没有违约记录 |
| **结算回笼** | 授信后能不能带来结算业务（决定这笔业务综合收益） |
| 额度使用 | 授信给了用不用、用得怎么样 |

### 4.6 看"增量"：本次申报与前次批复的差异

**这是贷前调查里最容易被忽略、但价值极高的一节。**

| 对比项 | 为什么重要 |
|---|---|
| 本次申请金额 vs 上次批复额度 | 为什么突然要多借？ |
| 本次用途 vs 上次用途 | 用途变了吗？ |
| 上次批复条件落实情况 | 上次答应的条件做到了吗？ |
| 财务数据变化 | 上次到现在，经营是变好还是变差？ |

> 🔴 **业务逻辑**：老客户不是"重新看一遍"，而是**看变化**。
> "上次批了 3000 万，这次要 8000 万"——**多出来的 5000 万要干什么？** 这才是审批人最关心的。

## 第五部分 · 项目评估专项（固贷 / 房开贷）

> 这一节是"项目类贷款"的核心。**固贷的还款来源是项目本身**，所以必须把项目算清楚。

### 5.1 项目的"合规性"（第一步，也是最容易被忽略的）

**项目贷款必须先把手续看全，手续不全的直接不能做。**

| 手续 | 说明 |
|---|---|
| **项目立项批复** | 政府同意这个项目建 |
| **可研报告批复** | 可行性研究报告获批 |
| **土地批复 / 土地证** | 地是哪来的、有没有合法取得 |
| **建设用地规划许可证** | 这块地允许建 |
| **建设工程规划许可证** | 允许这么建 |
| **施工许可证** | 允许开工 |
| **环保批复（环评）** | 环保达标 |
| **其他行政许可** | 行业特殊要求（如危化品、矿产） |

> 🔴 **俗称"四证"**：土地证 + 建设用地规划许可 + 建设工程规划许可 + 施工许可。
> **没有四证就放款，属于严重违规。**

### 5.2 投资估算与融资方案——钱从哪来

**一个项目要花的钱，必须说清楚每一分从哪出。**

| 构成 | 说明 |
|---|---|
| **项目总投资** | 建设投资（工程费+其他费用+预备费）+ 建设期利息 + 铺底流动资金 |
| **资本金** | **股东自己掏的钱**（监管有最低比例要求，如 20%~30%） |
| **银行借款** | 银行出多少 |
| **其他来源** | 政府补助、股东借款、其他融资 |

> 🔴 **资本金是项目贷款的"安全垫"**：
> **资本金不到位，说明股东自己都不想投，凭什么让银行出钱？**
> 所以调查要查：资本金**来源是否合法合规**、**是否真到位**（不是口头承诺）。
> 而且资本金必须**先于银行贷款到位**（这是监管要求）。

### 5.3 项目财务效益测算——项目自己能赚钱吗

**核心逻辑**：预测项目建成后的收入、成本、利润，看投资回本能力。

| 测算内容 | 说明 |
|---|---|
| **项目收入估算** | 靠什么收钱、价格多少、量多少（房开贷=卖房收入） |
| **项目成本估算** | 原材料、人工、能耗、折旧、利息 |
| **现金流量测算** | 每年净现金流多少、什么时候回本 |
| **损益表预测** | 每年的利润情况 |

**关键指标**：

| 指标 | 含义 |
|---|---|
| **内部收益率（IRR）** | 项目自身的回报率，要高于资金成本 |
| **净现值（NPV）** | 折现后是否为正 |
| **投资回收期** | 几年能把投资收回来 |
| **盈亏平衡点** | **产量/价格降到多少就不赚钱了** |

### 5.4 贷款偿还能力测算——用项目现金流还银行

**这是项目贷款的"命门"**：不看企业整体，看**这个项目自己**能不能还上贷款。

| 测算 | 说明 |
|---|---|
| **可用于还贷的现金流** | 项目净利润 + 折旧摊销（+ 其他非付现成本） |
| **每年应还本息** | 按还款计划算 |
| **偿债覆盖率（DSCR）** | 可用现金流 ÷ 应还本息 |
| **贷款期限 vs 项目周期** | 贷款期限要匹配项目回款节奏 |

> 🔴 **业务常识**：一般要求**偿债覆盖率 ≥ 1.2~1.3**。
> 意思是"能还的钱要比该还的钱多出 20%~30%"，留出波动余地。
> 覆盖率低于 1，意味着项目赚的钱**都不够还贷**——这种项目不能做。

### 5.5 不确定性分析——"万一"怎么办

项目测算都是**预测**，所以必须做"如果不如预期"的测试：

| 方法 | 说明 |
|---|---|
| **敏感性分析** | 单一因素（售价、成本、销量、工期）变动时，指标变化多少 |
| **盈亏平衡分析** | 保本点在哪 |
| **不确定性分析** | 多因素组合下的风险 |

> 🔴 **业务价值**：敏感性分析告诉你**"最怕什么"**。
> 如果"售价下降 10% 项目就不赚钱了"，那这个项目对房价**极度敏感**——
> 在调控周期里，风险就很大。

### 5.6 房开贷独有：销售与回笼监管

**房开贷的还款来源 = 卖房回款**，所以最核心的两个问题：

| 问题 | 对应调查内容 |
|---|---|
| **卖得出去吗** | 楼盘区位、周边配套、去化率、销售进度 |
| **卖了的钱去哪了** | **销售回笼资金使用情况**（有没有被抽走挪用） |

**常见的资金监管要求**：
- 销售回款必须归集到监管账户
- 按销售进度按比例归还贷款
- 资金使用需银行审批

> 🔴 **房开贷最常见的雷**：房子卖得不错，但**回款被集团抽走用到别的项目上**，
> 结果这个项目该还贷款时没钱了。所以"销售回笼资金使用情况"是房开贷贷后/贷前都要盯死的一项。

## 第六部分 · 授信调查的"三查"与常见误区

### 6.1 信贷"三查"

| 环节 | 内容 |
|---|---|
| **贷前调查** | 客户情况、经营、财务、用途、还款来源、担保 |
| **贷时审查** | 独立复核（审查岗不受客户经理影响）、合规性、风险判断 |
| **贷后检查** | 定期回访、监控变化、落实批复条件 |

> 三者相互独立、相互制衡。**客户经理（调查）和审查岗（审查）必须分开**——这是内控要求。

### 6.2 贷前调查最常见的 8 个误区

| # | 误区 | 正确做法 |
|---|---|---|
| 1 | 客户要多少就报多少 | **必须做资金需求量测算**，算出来是数 |
| 2 | 有抵押物就放心 | 抵押物是**第二还款来源**，第一还款来源才是根本 |
| 3 | 报表好看就是好客户 | 要看**税、流水、电费、代发**能不能对上；要看账龄 |
| 4 | 老客户不用细看 | 老客户要看**变化**（本次 vs 前次批复差异） |
| 5 | 只看借款人，不看关联方 | 集团、股东、实控人其他公司**都要看**（风险会传导） |
| 6 | 项目有批复就行 | **四证 + 环评 + 资本金到位**逐项核；手续不全不能做 |
| 7 | 测算按最好的情况算 | 必须做**敏感性分析 + 盈亏平衡**，看"万一" |
| 8 | 担保人签了字就有效 | 要看担保人**代偿能力**；法人互保常是形式担保 |

### 6.3 一句话记住贷前贷后的关系

```
贷前调查   →  决定"借不借、借多少、什么条件"
   ↓（批复条件）
贷后检查   →  验收"条件落实了没有、风险变了没有"
   ↓（发现风险）
预警处置   →  采取行动（压降、追加担保、提前收贷）
```

**贷前许下的条件，就是贷后要验收的清单。** 两者是一套闭环，不是两件事。
