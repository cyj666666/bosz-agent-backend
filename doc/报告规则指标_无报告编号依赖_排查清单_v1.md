## 五、修复方向（待拍板）

1. **补齐配置**：给这 153 个指标的 `script` 配上带条件的 SQL —— 至少 `WHERE REPORTNO = :reportNo`（如需客户维度再并 `AND CUSTOMERNAME = :entName`），并在 `paramData` 里声明 `reportNo`；
2. **堵住根因**（更根本）：`JoinSql()`（`IndexParamsServiceImpl:121`）在 `script` 为空时拼出的是 `SELECT 列 FROM 表`（**无 WHERE**）。应改为**拒绝生成**或**必须传入关联条件**，避免"无参取数"这种配置被静默接受；
3. 取数层兜底：`params` 为空且该指标属于报告链路时，应直接判为"未取到值"（而不是拿全表第一行算出一个看起来正常的值）。

配套排查 SQL（可重复执行）：

```sql
SELECT DISTINCT p.paramno, p.paramname, p.columnfromtable, p.acturecolumn, r.rule_code, r.rule_name
FROM index_params p JOIN agent_rule r ON position(p.paramno in r.parsed_expression) > 0
WHERE p.scripttype = 'Sql' AND (p.script IS NULL OR length(p.script) = 0)
ORDER BY p.paramno, r.rule_code;
```
