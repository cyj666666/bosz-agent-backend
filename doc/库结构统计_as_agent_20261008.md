## 六、迁移前必须确认的口径风险

| 风险 | 说明 |
|---|---|
| 🔴 **外网 ≠ 行内 SIT** | 本报告来自外网本地库。外网开发通常**领先**行内（历史上出现过本地库缺列、行内同步滞后等情况），真正迁移前**必须在行内 SIT 上跑同一套统计**做 diff，以行内为准 |
| 🔴 **兼容模式差异** | 本地库 `sql_compatibility = B`（MySQL 兼容），行内为 `M` 模式。同一份 DDL 在两边行为可能不同（类型名、`||`、`to_char` 等），迁移脚本需按 **M 模式交集语法** 重写 |
| 🟡 **字符集/排序规则** | 迁移前确认 SIT 与 UAT 的 `lc_collate` / 编码一致，避免索引失效 |
| 🟡 **序列当前值** | 135 个序列的 `last_value` 若一并迁移，需保证 ≥ 现有数据最大 id，否则插入冲突 |
